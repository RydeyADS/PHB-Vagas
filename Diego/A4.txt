# 1. Importação dos Arquivos

```javascript
import { vagas } from '../Kayo/dados.js';
import { gerarCardVaga } from '/Kayo/funcoes.js';
```

### O que faz?

Importa informações de outros arquivos do projeto.

### Explicação

* `vagas` contém todas as vagas cadastradas.
* `gerarCardVaga()` gera o HTML de cada vaga.

### Objetivo

Separar o projeto em módulos para facilitar a organização.

---

# 2. Criação da Função Principal

```javascript

```

### O que faz?

Cria a função responsável por exibir toda a tela de vagas.

### Objetivo

Centralizar toda a lógica relacionada à listagem de vagas.

# 3. Montagem da Estrutura HTML

```javascript
let html = `
    <div class="container mt-5">
        <h2 class="mb-4 text-center">
            Vagas Disponíveis
        </h2>
`;
```

### O que faz?

Cria o HTML da página utilizando Template Strings.

### Explicação

Em vez de escrever diretamente no HTML, a estrutura é criada dinamicamente pelo JavaScript.

### Objetivo

Permitir gerar conteúdo automaticamente.

---

# 4. Percorrendo as Vagas

```javascript
vagas.forEach(vaga => {
    html += gerarCardVaga(vaga);
});
```

### O que faz?

Percorre todas as vagas cadastradas.

### Explicação

Para cada vaga encontrada:

1. Chama a função `gerarCardVaga()`.
2. Cria um card.
3. Adiciona esse card ao HTML.

### Objetivo

Mostrar todas as vagas cadastradas automaticamente.

---

# 5. Inserindo o Conteúdo na Página

```javascript
document.querySelector('#app').innerHTML = html;
```

### O que faz?

Substitui o conteúdo da página pelo HTML gerado.

### Explicação

* `querySelector()` localiza o elemento.
* `innerHTML` insere o conteúdo.

### Objetivo

Exibir as vagas para o usuário.

---

# Conceitos de JavaScript Utilizados

Durante o desenvolvimento foram utilizados diversos conceitos importantes:

### Módulos

```javascript

```

Permitem dividir o sistema em vários arquivos.

---

### Funções

```javascript

```

Utilizadas para organizar a lógica do programa.

---

### Arrays

```javascript

```

Permitem armazenar várias vagas.

---

### Eventos

```javascript

```

Permitem responder às ações do usuário.

---

### Manipulação do DOM

```javascript

getElementById()
innerHTML
```

Permitem modificar elementos da página.

---

### Requisições

```javascript

```

Permite carregar arquivos dinamicamente.

---

# Conclusão

O arquivo `vagas.js` é responsável por controlar toda a navegação relacionada às vagas de emprego. Ele exibe as oportunidades cadastradas, permite que o usuário abra o formulário de candidatura, captura os dados preenchidos e apresenta uma mensagem de sucesso após o envio. Além disso, utiliza conceitos importantes de JavaScript moderno, como módulos, eventos, manipulação do DOM e requisições com Fetch API.
